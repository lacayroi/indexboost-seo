# Screenshots Checklist — IndexBoost SEO App Store Submission

Shopify requires at least 3 screenshots. Recommended: 6–8 screenshots showing key features.
Resolution: 1600×900 px (16:9) or 1200×628 px. PNG or JPG.

## Required Screenshots

- [ ] **01_dashboard.png** — Main dashboard showing submission stats, quota meter, and quick-submit section. Capture on a Pro/Business plan store with real data.
- [ ] **02_auto_indexing_settings.png** — Settings page showing auto-indexing toggles for products, collections, pages, blogs; Google credentials status; IndexNow key.
- [ ] **03_ai_seo_optimizer.png** — AI SEO page showing product list with SEO scores, "Generate SEO" button, and a preview of generated title + description.
- [ ] **04_meta_tags_editor.png** — Meta Tags editor showing the product/collection/page list with SEO title/description length badges and the edit modal open.
- [ ] **05_submission_logs.png** — Submission logs table showing Google + IndexNow entries with status badges (success/failed), timestamps, and URL.
- [ ] **06_redirect_manager.png** — Redirect Manager showing a list of URL redirects with the "Add Redirect" modal open.

## Optional Screenshots (Recommended)

- [ ] **07_billing_plans.png** — Plans & Billing page showing Free / Pro / Business cards with feature lists and pricing.
- [ ] **08_robots_txt_editor.png** — Robots.txt editor showing the text editor with save button and the current robots.txt content.
- [ ] **09_image_seo.png** — Image SEO page showing product images, alt text status badges, and "Apply Smart Alt Text" banner.
- [ ] **10_seo_audit.png** — SEO Audit results showing issues found with severity badges.

## Screenshot Guidelines

1. Use a **Development Store** with at least 5–10 products with real data
2. Ensure the Shopify Admin iframe frame is visible (shows embedded app correctly)
3. Capture at 1x resolution — do not use retina/2x without scaling down
4. No personal data visible (blur out shop domain if needed)
5. Match the screenshots to the feature descriptions in `FINAL_APP_REVIEWER_GUIDE.md`

## App Icon Requirements

- Size: 1200×1200 px (Shopify requirement)
- Format: PNG with transparent background or solid white background
- Do not use the Shopify logo or any Shopify branding
- File: `app-icon-1200x1200.png`
